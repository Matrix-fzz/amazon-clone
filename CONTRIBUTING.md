# Contributing to Amazon Clone

Thank you for your interest in contributing to this project! We welcome all contributions, from bug reports to new features.

## How to Contribute

### Reporting Bugs

- Search the existing issues to ensure the bug hasn't already been reported.
- If it's a new bug, open an issue with a clear title and description.
- Provide steps to reproduce the bug and any relevant screenshots.

### Suggesting Features

- Open an issue with the [Feature Request] label.
- Clearly describe the feature and its potential benefits.
- Participate in the discussion to refine the proposal.

### Pull Request Process

1. Fork the repository and create a new branch for your changes.
2. Ensure your code follows the project's style guidelines (run `npm run lint`).
3. Write clear, concise commit messages.
4. Update documentation if your changes introduce new features or change existing ones.
5. Create a pull request with a detailed description of your changes.
