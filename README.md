# Amazon Clone - React + Vite

A modern, responsive e-commerce application built with React 19 and Vite, styled to look and feel like Amazon.

## 🚀 Features

- **Product Listing:** Browse through a wide range of products with detailed information.
- **Search Functionality:** Find products quickly using the real-time search bar.
- **Shopping Cart:** Add, remove, and manage items in your cart with automatic total calculation.
- **Responsive Design:** Seamless experience across desktop, tablet, and mobile devices.
- **State Management:** Efficiently managed using React Context API.
- **Routing:** Smooth navigation powered by React Router.

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite
- **Styling:** Vanilla CSS
- **Routing:** React Router 7
- **State Management:** Context API
- **Icons/Assets:** Custom CSS and SVG assets

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd amazon-clone
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser to view the application.

### Building for Production

To create a production build:

```bash
npm run build
```

The optimized files will be generated in the `dist/` directory.
